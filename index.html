Keyboard shortcuts

Commands are also available from the pane menus, with their keyboard shortcuts printed beside them. Markdown takes shape as you type: use # for headings, ** for bold, and - for lists. Writing commands handle the larger operations — checklists, code blocks, tables, attachments and templates.

Moving around

↑ ↓
Move through notes, in the list or while searching
Enter
Open the note, or create one titled with the search when nothing matches
Shift Enter
Create a note titled with the search, even when there are matches
#tag
Anywhere in a note; click a tag in the sidebar or search #tag to filter
#tag/part
Nests one tag inside another; the parent finds everything filed under it
[[Note title]]
Links to another note — click it to go there, or to start it. Notes pointing here, related notes, and notes that say this note’s name without linking it, are listed under the words
![[Note title]]
On a line of its own, shows that whole note here; ![[Note#Heading]] shows one section of it. What is shown is what that note says now
aliases:
Other names a note answers to (Ctrl+Shift+A). A link or a search naming one finds the note; they are kept in its front matter
todo: due:today
In the search box: operators narrow the list — tag: todo: done: due: pinned: created:>7d updated: links: orphan: sort:title limit: and /regex/
- [ ] task @2026-09-10
A date on a checklist line schedules it; add a time (@2026-09-10 14:30) and Notes reminds you then, or at nine that morning
#template {{date}}
A note tagged #template is a template; {{title}}, {{date}}, {{time}} and {{date:DDD D MMM}} are filled in when it is used
$x^2$ ```mermaid
Math between dollars ($$ on its own lines for a block) and mermaid fences render in the preview and every export
**bold** # Heading
Markdown takes its shape as you write it; the markers fade, and hide on every line but the one you are on
--- Enter
Turns into a section divider
| a | b |
A table. Ctrl Shift J makes one or lines up the one you are in; Tab moves between cells and the last cell makes a row
Click a heading
In the outline beside the note, jumps there
Click an image
Select it, then drag the corner handle to resize; double-click for the original size
Alt ↑ / Alt ↓
Move the selected image up or down a line (or drag it)
Drop a file
Images attach; .md and .txt files come in as notes
Ctrl Alt J
Anywhere in Windows: a quick-note box that files a line in the Inbox note (change it in Layout)
Ctrl 1 … 9
The nth note open in this pane; Ctrl 9 is the last of them
Middle-click a tab
Closes it, as it does in a browser
Esc
Back to the list, clear the search, or cancel

Journal

          

            Where entries go
            
            
          

          
A path for the dated note, where a slash makes a folder. YYYY, MM, DD, MMM and DDD become the date; anything else is the word it is. Changing this affects the days you open from now on — notes already written are not moved.


          
Files

          

            Notes folder
            One markdown file per note.
            
            
          

          
Choose a folder in OneDrive, Dropbox or a git checkout and the notes are backed up and readable anywhere. An empty folder takes the notes you have; a folder that already holds notes becomes the notebook as it is.

          

            Web clipper
            A bookmarklet that saves the page you are reading, or the words you have selected, as a note.
            
          

          
Copy it, then make a new bookmark in your browser and paste it as the address. It works while Notes is running.
