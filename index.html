Keyboard shortcuts

Ctrl N
New note
Ctrl K / Ctrl F
Find a note
↑ ↓
Move through notes, in the list or while searching
Enter
Open the note, or create one titled with the search when nothing matches
Shift Enter
Create a note titled with the search, even when there are matches
Ctrl Shift P
Pin or unpin the note to the top of the list
#tag
Anywhere in a note; click a tag in the sidebar or search #tag to filter
Ctrl ↑ / Ctrl ↓
Previous or next note from anywhere
Ctrl E
Toggle markdown preview
Ctrl Shift I
Attach an image (or paste / drop one)
Click an image
Select it, then drag the corner handle to resize; double-click for the original size
Alt ↑ / Alt ↓
Move the selected image up or down a line (or drag it)
Ctrl Shift S
Export as Markdown, plain text or image
Ctrl S
Save now (autosave is always on)
Ctrl Shift D
Delete note, press again to confirm
Ctrl \
Toggle sidebar
Esc
Back to the list, clear the search, or cancel
Ctrl /
This sheet

Press Esc to close
