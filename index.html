Keyboard shortcuts

Moving around

↑ ↓
Move through notes, in the list or while searching
Enter
Open the note, or create one titled with the search when nothing matches
Shift Enter
Create a note titled with the search, even when there are matches
#tag
Anywhere in a note; click a tag in the sidebar or search #tag to filter
#tag/part
Nests one tag inside another; the parent finds everything filed under it
[[Note title]]
Links to another note — click it to go there, or to start it. Notes pointing here, and related notes, are listed under the words
todo: due:today
In the search box: operators narrow the list — tag: todo: done: due: pinned: created:>7d updated: links: orphan: sort:title limit: and /regex/
- [ ] task @2026-09-10
A date on a checklist line schedules it; add a time (@2026-09-10 14:30) and Notes reminds you then, or at nine that morning
#template {{date}}
A note tagged #template is a template; {{title}}, {{date}}, {{time}} and {{date:DDD D MMM}} are filled in when it is used
$x^2$ ```mermaid
Math between dollars ($$ on its own lines for a block) and mermaid fences render in the preview and every export
**bold** # Heading
Markdown takes its shape as you write it; the markers fade, and hide on every line but the one you are on
--- Enter
Turns into a section divider
Click a heading
In the outline beside the note, jumps there
Click an image
Select it, then drag the corner handle to resize; double-click for the original size
Alt ↑ / Alt ↓
Move the selected image up or down a line (or drag it)
Drop a file
Images attach; .md and .txt files come in as notes
Ctrl Alt J
Anywhere in Windows: a quick-note box that files a line in the Inbox note (change it in Layout)
Esc
Back to the list, clear the search, or cancel
